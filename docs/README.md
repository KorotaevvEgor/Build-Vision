## Где искать реализацию

- `backend/app/matching.py` — выбор работы и количественное сопоставление.
- `backend/app/matching_evidence.py` — пространственное назначение техники работе.
- `backend/app/evidence.py` — независимость и повторяемость наблюдений.
- `backend/app/deviations.py` — формирование и жизненный цикл предупреждений.
- `backend/app/correction_tasks.py`, `correction_training.py`, `correction_activation.py` — коррекции, обучение и публикация модели.
- `frontend/src/components/DeviationWalkthrough.tsx` — шесть интерактивных разборов.
- `scripts/evaluate_detector.py` — оценка распознавания по размеченной выборке.

Скриншоты в README показывают учебные разборы интерфейса. Условия этих примеров не используются как реальные доказательства отклонений.
